# Tech Blog Development Log

This log documents the journey of building and improving this technical blog.

## 2025-12-07 | Nextra Migration

Nextra 4로 블로그 UI를 완전히 재설계했다.

Key changes:
- Nextra 4 기반 Wiki + Blog 하이브리드 구조
- 미니멀 디자인 (색상 최소화)
- 문서 중심 구조화

## 2025-07-25 | Update About Page

About Page가 포트폴리오처럼 보일 수 있도록 UI를 업데이트했다.

Key features added:

- About Page 디자인 업데이트
- 기본 Font를 Gmarket Sans로 변경
- 헤더 아이콘, 페이지 파비콘, 페이지 타이틀 디자인 적용

## 2025-07-23 | Initial Blog Setup

Claude code와 함께 Next.js 15, tailwind css로 기술블로그 UI를 만들었다.

Key features added:

- Next.js 15 with App Router
- Markdown content processing with remark
